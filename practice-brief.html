The practice intelligence layer

Not software that does taxes. A system that prepares every engagement before judgment begins — what changed, what’s missing, what to ask — with every number linked to the exact source page it came from. The accountant reviews, decides, and signs. Always.

The bottleneck is intake and reconciliation — not judgment

The rule that makes it trustworthy
Nothing publishes unless it ties out.

If a document’s numbers fail to reconcile against its own printed control totals, the build halts and no report exists. This is not a promise — it is running in production today: Public Ledger reads the City of North Tonawanda’s published warrant PDFs — 36 of 36 machine-readable documents reconciled to the penny, 8,532 line items, $28.1M — and cannot show a number that failed its own check.

✓ ALL GATES PASS: name fidelity · expenditure tie-out · row count · list amount  — actual output of the last build

A bank statement prints its balances. A transcript prints its totals. Last year’s return is the baseline. Same gate, different letterhead.

The plan — each phase its own win

01 · NOW → DECEMBER

Bookkeeping pilot

Five friendly clients. Bank and card statements in, reconciled to their own printed balances, a monthly exception brief out: uncategorized items, anomalies against that client’s own history, missing documents.

Measured in minutes saved per close — proven before tax season opens.

02 · JANUARY → APRIL

Tax review assist

A one-page briefing per return, before review: prior-year deltas, a missing-document checklist (IRS transcript diff for extensions), flags with links to source pages. Extraction stays commodity — GruntWorx, SurePrep, or the software’s own scan.

The gate and the briefing are ours.

03 · LATER

Buy, don’t build

Intake stays in TaxDome — clients already live there. Document OCR is bought, never rebuilt. No new portal, no tax engine, no rip-and-replace.

The layer enhances the tools the practice already trusts.

Built to the practice’s own obligations

IRC §7216 — return information is criminally protected: processing runs on a machine in the office, and nothing reaches any third-party model without written consent and zero-retention terms. FTC Safeguards Rule — the firm’s written security plan (IRS Pub 4557) is the design document: encryption, access controls, an audit log for every action, explicit deletion. And every extracted number carries a link to its exact source page, so review is fast and human judgment stays in charge.
